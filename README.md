# Python, NumPy & Pandas - Assessment Prep

Course notes, case studies and a 250-question practice bank for the Python / NumPy / Pandas assessment.

## Contents

| Folder | What's inside |
|---|---|
| `01_python_fundamentals/` | Basics, control flow, loops, lists, slicing, strings, 2D lists, sets & dictionaries, functions |
| `02_numpy/` | NumPy basics, operations, advanced indexing / broadcasting, **Fitbit** case study |
| `03_pandas/` | Pandas basics (**McKinsey** case study), merge / groupby (**IMDB** case study), descriptive statistics |
| `assessment_prep/` | **250 practice questions** (MCQ + coding) with fully worked, tested solutions |
| `datasets/` | `fitness.txt`, `mckinsey.csv`, `movies.csv`, `directors.csv` used by the notebooks and questions |

|---|---|---|---|

### How to use
1. Put the files from `datasets/` next to your notebook, then run the set-up cell shown at the top of each question file.
2. Attempt a section without looking at the solutions, then compare.
3. Re-do the questions you got wrong 2-3 days later.
