# Python, NumPy & Pandas – Assessment Prep

Course notes, case studies and a practice question bank for the Python / NumPy / Pandas assessment.

## Contents

| Folder | What's inside |
|---|---|
| `01_python_fundamentals/` | Basics, control flow, loops, lists, slicing, strings, 2D lists, sets & dictionaries, functions |
| `02_numpy/` | NumPy basics, operations, advanced indexing/broadcasting, **Fitbit** case study |
| `03_pandas/` | Pandas basics (**McKinsey** case study), merge / groupby (**IMDB** case study), descriptive statistics |
| `case_studies/` | Stand-alone case study notebooks (Fitbit, Starbucks, IMDB, McKinsey) |
| `assessment_prep/` | ~50 most probable assessment questions (coding + MCQ), focused on NumPy and Pandas |
| `datasets/` | Data files used by the notebooks |

## How to use
1. Work through the notebooks in numeric order inside each folder.
2. Re-solve each case study without looking at the solution.
3. Attempt the questions in `assessment_prep/` under timed conditions.
